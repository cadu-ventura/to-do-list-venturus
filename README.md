# To Do List

Lista de tarefas feita com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas
- Ver quantas tarefas estão pendentes e quantas estão concluídas
- Clicar na tarefa para marcar como concluída (ou voltar para pendente)
- Excluir tarefas no botão **X**
- Arrastar e soltar tarefas entre as colunas

## Como usar

1. Baixe ou clone o repositório:
   ```
   git clone https://github.com/cadu-ventura/to-do-list-venturus.git
   ```
2. Abra o arquivo `index.html` no navegador.

## Estrutura

```
index.html        → estrutura da página
css/style.css     → estilo da página
js/script.js      → funcionamento da lista
assets/img/       → logos
```

## Etapas do projeto

1. Estrutura HTML
2. Estilo CSS
3. Adicionar tarefas
4. Concluir e excluir tarefas
5. Arrastar e soltar
